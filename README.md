# 🎓 Congraduation

세종대학교 학생의 졸업요건과 공학인증(ABEEK) 충족 현황을 한눈에 확인하고,
남은 학기의 수강 계획을 세울 수 있는 웹 서비스입니다.

기이수성적 엑셀 파일을 한 번 업로드하면 영역별 이수 현황, 부족 학점,
공학인증 평가와 이수체계도를 학생 정보에 맞춰 제공합니다.

> 본 저장소는 Congraduation의 프론트엔드 애플리케이션입니다.

## 주요 기능

- **졸업요건 분석**: 전공·교양·학문기초 등 영역별 이수 학점과 남은 요건 확인
- **공학인증 평가**: ABEEK 인증 영역별 충족 현황과 세부 과목 조회
- **기이수과목 관리**: 학사정보시스템에서 내려받은 성적 파일 업로드 및 갱신
- **이수체계도**: 학과와 입학연도에 맞는 교과과정 및 이수 여부 확인
- **졸업 시뮬레이션**: 학기와 수강 예정 과목을 추가해 예상 졸업요건 충족도 계산
- **전공 트랙 전환**: 복수전공 등 학생의 전공 이수 트랙별 현황 확인
- **문의 및 오류 신고**: 서비스 내 문의 등록과 처리 상태 조회
- **관리자 기능**: 수강편람·시간표 업로드, 문의 관리, 이용 통계 확인

## 이용 흐름

```text
개인정보 수집·이용 동의 및 로그인
  → 기이수성적 엑셀 업로드
  → 졸업요건·공학인증 분석
  → 이수체계도 확인 및 졸업 시뮬레이션
```

이미 성적 정보를 등록한 사용자는 로그인 후 바로 대시보드로 이동합니다.

## 시작하기

### 요구 사항

- Node.js 20.19 이상 또는 22.12 이상
- npm
- Congraduation 백엔드 API

### 설치 및 실행

```bash
git clone https://github.com/congraduation-team/congraduation-frontend.git
cd congraduation-frontend
npm install
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다.

### 환경 변수

프로젝트 루트에 `.env.local` 파일을 만들고 백엔드 API 주소를 설정할 수 있습니다.

```env
VITE_API_BASE_URL=http://localhost:8080
```

값을 설정하지 않으면 상대 경로(`/api`)로 요청합니다. 배포 환경에서는
`vercel.json`의 rewrite 설정을 통해 API 서버로 요청을 전달합니다.

## 성적 파일 업로드

1. 세종대학교 학사정보시스템에 접속합니다.
2. `수업/성적 → 성적 및 강의평가 → 기이수성적조회`로 이동합니다.
3. 조회 결과를 XLSX 형식으로 내려받습니다.
4. `/upload` 페이지에서 파일을 선택하거나 드래그해 업로드합니다.

- 지원 형식: `.xlsx`
- 최대 용량: 1MB
- 업로드한 원본 파일은 서버에 별도로 보관하지 않습니다.
- 한 번의 업로드로 졸업요건과 공학인증 정보가 함께 갱신됩니다.

## 프로젝트 구조

```text
src/
├── api/          # API 클라이언트, 엔드포인트, 응답 타입
├── components/   # 공통 UI, 차트, 레이아웃, 모달
├── context/      # 인증 및 전공 트랙 전역 상태
├── data/         # 화면 개발용 데이터
├── pages/        # 라우트 단위 페이지
└── utils/        # 과목·인증·숫자 처리 유틸리티
```

## 빌드 및 배포

```bash
npm run lint
npm run build
```

Vercel 배포를 기준으로 SPA fallback과 `/api` 프록시가 설정되어 있습니다.
다른 환경에 배포할 때는 모든 클라이언트 라우트를 `index.html`로 연결하고,
`VITE_API_BASE_URL` 또는 별도의 reverse proxy를 구성해야 합니다.

## 유의 사항

분석 결과는 입력된 성적 정보와 서버에 등록된 교과과정을 기준으로 제공되는
참고 자료입니다. 최종 졸업 가능 여부는 반드시 학과 사무실 및 학교의 공식 안내를
통해 확인해 주세요.
