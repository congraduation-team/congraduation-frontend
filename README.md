# 세종대학교 졸업 인증 분석

피그마 디자인 기반 졸업 요건 UI 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

## 페이지

| 경로 | 설명 |
|------|------|
| `/` | 로그인 |
| `/upload` | 기이수성적 엑셀 업로드 |
| `/dashboard` | 졸업요건 대시보드 |
| `/dashboard/engineering` | 공학인증 현황 |
| `/dashboard/courses` | 내 이수과목 |
| `/curriculum` | 이수체계도 |

로그인 시 개인정보 동의 체크 후 로그인 → 업로드 → 완료 순으로 대시보드에 진입합니다.
